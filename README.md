 Notes Sharing Website 📚

A simple and beginner-friendly Notes Sharing Website where users can create and manage their notes online.  
This project is built using Frontend and Backend technologies with database support.

Main Features

- User Signup & Login
- Add New Notes
- Edit Existing Notes
- Delete Notes
- Share Notes with Other Users
- Search Notes Easily
- Mobile Responsive Design

 Technologies Used

 Frontend
- HTML
- CSS
- JavaScript

 Backend
- Java
- Spring Boot

### Database
- MySQL

 How to Run This Project

 Step 1
Clone the repository to your system.

 Step 2
Create a MySQL database.

 Step 3
Open the project and update your database username and password in:

```properties
src/main/resources/application.properties
Step 4

Run the Spring Boot application using:

mvn spring-boot:run
Step 5

Open your browser and visit:

http://localhost:8080
